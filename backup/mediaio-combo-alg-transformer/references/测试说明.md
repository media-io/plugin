# combo_alg 数据转换器测试说明

以下命令均在 `media-plugin-skills` 仓库根目录执行。

## 1. 检查脚本语法

```bash
node --check skills/mediaio-combo-alg-transformer/scripts/combo-alg-transformer.mjs
```

命令成功时没有输出，退出码为 `0`。

## 2. 使用仓库 fixture 转换

```bash
node skills/mediaio-combo-alg-transformer/scripts/combo-alg-transformer.mjs \
  --workflow-list tests/mediaio-combo-alg-transformer/fixtures/text2image-soul-character.workflow.json \
  --model text2image_soul_character \
  --input tests/mediaio-combo-alg-transformer/fixtures/text2image-soul-character.input.json \
  --pretty
```

输出应为一个 JSON body，并满足：

- 顶层存在 `data`、`prev_task`、`explore`、`user_data`、`module`。
- `data.uni_fun_code` 为 `text2image_soul_character`。
- `data.fun_module` 和顶层 `module` 都为 `text2image`。
- `data.ai_config` 中 `prompt.input` 为 fixture 的 prompt。
- `width.input` 为 `848`，`height.input` 为 `1264`。
- 输出中不存在 `method`、`path`、`headers` 或 `task_id`。

也可以写入文件后检查：

```bash
node skills/mediaio-combo-alg-transformer/scripts/combo-alg-transformer.mjs \
  --workflow-list tests/mediaio-combo-alg-transformer/fixtures/text2image-soul-character.workflow.json \
  --model text2image_soul_character \
  --input tests/mediaio-combo-alg-transformer/fixtures/text2image-soul-character.input.json \
  --output /tmp/mediaio-combo-alg-body.json \
  --pretty
```

## 3. 运行自动化测试

```bash
node --test tests/mediaio-combo-alg-transformer/combo-alg-transformer.test.mjs
```

测试覆盖比例 option、`normal`、`backfill`、`append`、`prefix`、`used_array`、混合媒体、自动尺寸、国家分段和未知字段错误。

## 4. 一条命令执行真实接口测试

测试目标固定为：

```text
list:  https://vapi.media.io/v1/workflow/list?fun_module=text2image&page=0&page_size=40
model: text2image_soul_character
```

运行环境需要 Node.js 22，测试运行器直接使用 Node.js `fetch`：

```bash
node tests/mediaio-combo-alg-transformer/run-live-test.mjs
```

一次执行会完成以下步骤：

1. 请求真实 `workflow/list` 接口。
2. 从响应中提取 `text2image_soul_character`。
3. 将当前模型对象直接写入 `tests/mediaio-combo-alg-transformer/.output/text2image_soul_character.workflow.json`，文件根节点就是模型数据，不包含 `data.list` 包装。
4. 首次运行时生成 `text2image_soul_character.input.json` 用户输入模板。
5. 重新读取该 input JSON，并调用正式数据转换器。
6. 将完整 body 写入 `text2image_soul_character.combo-alg-body.json`，同时输出到终端。

默认生成的 input JSON 可以直接通过转换：

```json
{
  "inputs": {
    "prompt": "A cinematic portrait with soft natural light",
    "ratio": "2:3",
    "concurrency_patterns": 4
  },
  "context": {
    "countryLimited": "not_t3",
    "isPublic": false,
    "isSubscribed": false,
    "templateId": ""
  }
}
```

## 5. 修改用户输入后重新测试

第一次执行后，可以直接编辑：

```text
tests/mediaio-combo-alg-transformer/.output/text2image_soul_character.input.json
```

再次运行相同命令时，测试脚本不会覆盖该文件，而是读取你修改后的内容：

```bash
node tests/mediaio-combo-alg-transformer/run-live-test.mjs
```

需要恢复默认模板时执行：

```bash
node tests/mediaio-combo-alg-transformer/run-live-test.mjs --reset-input
```

也可以指定输出目录或已有的用户输入文件：

```bash
node tests/mediaio-combo-alg-transformer/run-live-test.mjs \
  --output-dir /tmp/mediaio-transform-test \
  --input /tmp/my-text2image-input.json
```

如果 `--input` 指向的文件不存在，测试脚本会先在该位置生成模板，再读取并执行转换。

## 6. 检查转换结果

打开生成的 `text2image_soul_character.combo-alg-body.json`，至少检查：

- 顶层包含 `data`、`prev_task`、`explore`、`user_data`、`module`。
- `data.uni_fun_code` 为 `text2image_soul_character`。
- `data.ai_config` 中的 prompt 与 input JSON 一致。
- 默认比例下 `width.input` 为 `848`，`height.input` 为 `1264`。
- 文件不包含 `method`、`path`、header 或 task ID。

测试运行器只调用 list 接口，不调用 `/v1/ai/create/combo_alg`。正式的 `combo-alg-transformer.mjs` 仍然不联网，只负责数据转换。
